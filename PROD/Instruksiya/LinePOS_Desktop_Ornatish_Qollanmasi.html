Line Kassa — Kompyuterga O'rnatish Qo'llanmasi

Telegram orqali yuborilgan o'rnatish faylini kompyuteringizga to'g'ri va xavfsiz o'rnatish bo'yicha bosqichma-bosqich ko'rsatma.

💡 Til eslatmasi: Kompyuteringiz (yoki Telegramingiz) tili Ruscha yoki Inglizcha bo'lishi mumkin. Shuning uchun qo'llanmada har bir bosqichdagi tugma nomi ikkala tilda ham keltirilgan (masalan, Run / Запустить).
1
Telegramdan yuklangan faylni ochish va ruxsat berish

Telegram orqali yuborilgan Line_kassa_Desktop_Setup.exe faylini yuklab olib, ustiga bosing. Shunda ekranda Telegramning xavfsizlik oynasi chiqadi (fayl .exe formatida ekanligi haqida ogohlantiradi).

Qaysi tugmani bosish kerak: Inglizcha: Run Ruscha: Запустить
📌 Qo'shimcha maslahat: "Remember for this file type" (Запомнить для этого типа файлов) katakchasiga belgi qo'yib qo'ysangiz, keyingi safar bunday so'rov chiqmaydi.
2
Windows xavfsizlik so'rovini tasdiqlash

Keyingi oynada Windows tizimining rasmiy xavfsizlik ogohlantirishi (Security Warning) paydo bo'ladi. Bu yangi o'rnatilayotgan barcha dasturlarda chiqadigan standart xavfsizlik jarayonidir.

Qaysi tugmani bosish kerak: Inglizcha: Run Ruscha: Запустить
🛡️ Eslatma: Agar Windows himoyasi (SmartScreen) to'liq ko'k oyna chiqarsa, "Подробнее" (More info) yozuvini bosing va pastda paydo bo'ladigan "Выполнить в любом случае" (Run anyway) tugmasini bosing.
3
Ish stoliga yorliq (shortcut) yaratish

Dasturni o'rnatish ustasi (Setup) ochiladi. Bu yerda dastur belgisini kompyuteringiz ish stoliga chiqarish tavsiya qilinadi.

Bajariladigan amal: ☑️ Create a desktop shortcut (Создать значок на рабочем столе)
So'ngra bosiladigan tugma: Inglizcha: Next Ruscha: Далее
4
O'rnatishni boshlash (Install / Установить)

Barcha parametrlar tayyor bo'ldi (Ready to Install). Endi dastur fayllarini kompyuteringizga to'liq o'rnatish uchun o'rnatish tugmasini bosing.

Qaysi tugmani bosish kerak: Inglizcha: Install Ruscha: Установить

🎉 5-Qadam: O'rnatish muvaffaqiyatli yakunlandi!

Fayllar ko'chirilib bo'lgach, oxirgi oynada Finish (Завершить) tugmasini bosing.

🚀 Line Kassa dasturi avtomatik ochiladi. Keyingi safar dasturga kirish uchun ish stolidagi (Desktop) Line Kassa belgisini ikki marta bosishingiz kifoya.
